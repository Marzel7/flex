DATA FLOW SUMMARY
================================================================================

STAGE A: WEBHOOK INGESTION (Zero RPC, <50ms)
  Helius → RAW webhook
    ↓
  /helius/webhook POST endpoint
    ↓
  Extract System Program transfers
    ↓
  Deduplicate by signature
    ↓
  Insert into sol_transfers
    ↓
  Update address_activity (rolling stats)
    ↓
  Enqueue to work_queue
    ↓
  HTTP 200 response (immediate)

STAGE B: PRIORITY WORKER (Continuous)
  Fetch highest priority addresses (unlocked, due)
    ↓
  Lock rows (prevent concurrent processing)
    ↓
  Score using latest DB signals
    ↓
  Check RPC guardrails
    ↓
  Process (optional RPC call if gated)
    ↓
  Update metadata (last_processed_at, attempts)
    ↓
  Requeue for 5 minutes from now

================================================================================
DATABASE SCHEMA
================================================================================

sol_transfers (Primary key: signature)
  - signature, slot, block_time
  - source, destination
  - lamports, amount_sol
  - received_at, processed
  - Indexes: source, destination, block_time, received_at

address_activity (Primary key: address)
  - last_seen_at (timestamp of most recent transfer)
  - tx_5m, tx_1h, tx_24h (transaction counts)
  - sol_in_5m/1h/24h, sol_out_5m/1h/24h (SOL flows)
  - last_processed_at, last_rpc_fetch_at
  - Indexes: last_seen_at, updated_at

work_queue (Primary key: address)
  - priority (computed score)
  - reason (why queued)
  - next_run_at (when eligible)
  - locked_until (prevents concurrent processing)
  - attempts (processing counter)
  - Indexes: priority DESC, next_run_at ASC

================================================================================
PRIORITY SCORING
================================================================================

Score = activity + tag + network + multi_token - cooldown

ACTIVITY:
  +50 if last_seen < 5m
  +30 if last_seen < 1h
  +20 if tx_1h >= 5
  +15 if (sol_in_1h + sol_out_1h) > 10 SOL

TAGS (from creator_tags table if exists):
  +60 watchlist or known_malicious
  +40 suspicious

NETWORK:
  +30 in cluster (from super_clusters)
  +20 coordinated_funder (from coordinated_funders)

MULTI-TOKEN:
  +20 if created >= 2 tokens (from token_analysis)

COOLDOWN:
  -50 if processed < 2m ago
  -20 if processed < 10m ago

================================================================================
RPC GUARDRAILS
================================================================================

RPC is allowed ONLY if:
  1. Priority >= 80 (high threshold)
  2. Last RPC > 30 minutes ago (cooldown)
  3. Calls this hour < 100 (global rate limit)

NEVER call:
  ❌ /v0/transactions (enhanced endpoints - FORBIDDEN)
  ❌ getSignaturesForAddress (unless behind gate)
  ❌ getProgramAccounts
  ❌ searchAssets

CAN call (if gated):
  ✅ getSignaturesForAddress (low-cost, basic)
  ✅ getAccountInfo (metadata)
