YOUR QUESTION: "Do the values in the database get updated? How do we know they're fresh?"

┌────────────────────────────────────────────────────────────────────────────────────┐
│ ANSWER 1: YES - Database Values ARE Automatically Updated                         │
└────────────────────────────────────────────────────────────────────────────────────┘

   When python main.py runs:
   
   ┌─────────────────────────────────────────────┐
   │  Background Price Update Thread             │
   │  (Runs continuously in daemon mode)         │
   └─────────────────────────────────────────────┘
           ↓
   Every 10 seconds:
   ├─ Check which pools need updating
   └─ For each pool needing update:
      ├─ Fetch LIVE price from blockchain
      ├─ Get token supply
      ├─ Calculate market cap = price × supply
      ├─ Fetch from DexScreener API
      ├─ Update database with new values
      └─ Record timestamp in last_price_update

   Update Frequency (Sliding Scale):
   
   ┌──────────────────┬─────────────────┬──────────────────┐
   │  Pool Age        │  Update Freq    │  Rationale       │
   ├──────────────────┼─────────────────┼──────────────────┤
   │ 0-5 minutes      │ Every 30s ⚡     │ New, volatile    │
   │ 5-30 minutes     │ Every 2min      │ Stabilizing      │
   │ 30+ minutes      │ Every 5min      │ Mature, stable   │
   └──────────────────┴─────────────────┴──────────────────┘

┌────────────────────────────────────────────────────────────────────────────────────┐
│ Database Timestamps That Track Freshness                                          │
└────────────────────────────────────────────────────────────────────────────────────┘

   Table: pools
   
   Column              │ Meaning                    │ Updates
   ────────────────────┼────────────────────────────┼─────────────────
   first_seen          │ Pool detection time        │ Once at creation
   last_price_update   │ When price was refreshed   │ Every update
   
   Age Calculation:
   age_seconds = (now - first_seen).total_seconds()
   
   Freshness Check:
   seconds_since_update = (now - last_price_update).total_seconds()
   if seconds_since_update < update_interval:
       price is FRESH ✓
   else:
       price NEEDS UPDATE
