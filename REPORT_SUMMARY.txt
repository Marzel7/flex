================================================================================
                       HOW DATA MAPS TOGETHER
================================================================================

Full Data Flow Chain:
  
  SENDER
    ↓ sends SOL
  FUNDER (tracked in creator_funders)
    ↓ funds creator
  CREATOR (tracked in token_analysis)
    ↓ sends SOL (tracked in creator_outgoing_transfers)
  RECIPIENT

When RECIPIENT is a FUNDER:
  → Indicates: Creator A → Funder → Creator B
  → Means: Coordination between Creator A and B
  → Tracked in: funding_chains (confidence >= 70)
  → Result: Flagged in creator_networks

When RECIPIENT is a SENDER:
  → Indicates: Circular funding flow
  → Means: Money cycle A → B → A → B
  → Tracked in: coordinated_creator_edges
  → Result: High risk network

When RECIPIENT is CEX/Infra:
  → Indicates: Creator withdrawing/paying fees
  → Means: Normal activity (not suspicious)
  → Tracked in: recipient_type column
  → Result: Filtered from suspicious patterns

Self-Funding Detection:
  Creator creates 942 intermediaries
    → Each intermediary receives SOL
    → Each intermediary ONLY sends back to creator
    → Creator then launches 23 tokens
  Tracked in: creator_self_funding
  Result: Flagged as is_self_funding = 1
