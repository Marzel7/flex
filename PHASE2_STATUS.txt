================================================================================
                          TECHNICAL NOTES
================================================================================

DETECTION ALGORITHM
  A token is PumpSwap if:
    bonding_curve field is NOT None
    AND raydium_pool field is NOT None
  
  This is deterministic:
    - Regular Raydium: has raydium_pool, NO bonding_curve
    - Still bonding: has bonding_curve, NO raydium_pool
    - PumpSwap: has BOTH (migrated)

BROADCAST DATA
  Each PumpSwap token receives:
    'is_pumpswap': True
    'pumpswap_badge': '🚀 PumpSwap'
  
  UI can use these to display special PumpSwap indicator

DATABASE PERSISTENCE
  All detected tokens stored in 'pools' table:
    - is_pumpswap (flag)
    - pumpfun_creator (creator address)
    - bonding_curve_address (original bonding curve)
    - pumpfun_migration_timestamp (when migrated)
    - pumpfun_launch_time (when bonding curve started)
    - pumpfun_launch_price (initial curve price)
    - pumpfun_final_price (final curve price)
    - pumpswap_initial_price (price at migration)
    - creator, website, twitter, discord (metadata)
