      <div class="col-12">
          <div id="top-movers-container"></div>
      </div>
  </div>

STEP 4: Hook SSE Handler
────────────────────────
In initPriceStream(), modify es.onmessage:

  es.onmessage = (event) => {
      try {
          const update = JSON.parse(event.data);
          if (update.type === 'price_update') {
              updateTokenPrice(update);
              handlePriceUpdateForMovers(update);  // ← ADD THIS
          }
      } catch (error) {
          console.error('[PRICE_STREAM] Parse error:', error);
      }
  };

STEP 5: Initialize
──────────────────
In window.addEventListener('load', ...):
  TOP_MOVERS.init();  // ← ADD THIS

📊 DATA FLOW (FOR REFERENCE)
================================================================================

Price Stream (SSE)
    ↓
EventSource.onmessage
    ├→ updateTokenPrice()          [dashboard update]
    └→ handlePriceUpdateForMovers() [Top Movers]
        ↓
TOP_MOVERS.onPriceUpdate()
    ├─ Store price in history
    ├─ Prune old prices (> 5 min)
    └─ Schedule render (debounced)
        ↓ (batched every 1 second)
TOP_MOVERS.render()
    ├─ Calculate gainers (% change)
    ├─ Calculate losers (% change)
    ├─ Calculate active (update count)
    └─ Render HTML to #top-movers-container

🔍 TROUBLESHOOTING
================================================================================

Panel blank?
  → Wait 5-10 seconds for data
  → Check console: should see [PRICE_STREAM] ✅
  → Verify SSE is connected

Not updating?
  → Check handlePriceUpdateForMovers is called
  → Verify #top-movers-container exists in HTML
  → Ensure TOP_MOVERS.init() was called

Memory leak?
  → Monitor DevTools → Memory tab
  → Should stay flat after 5 minutes
  → Old data is automatically pruned

High CPU?
  → Check renderIntervalMs isn't too low
  → Verify pruneHistory is working

See TOP_MOVERS_INTEGRATION.md for more troubleshooting
