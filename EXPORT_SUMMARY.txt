CSV COLUMN DEFINITIONS
===============================================================================

1. mint
   - Token mint address (Solana blockchain identifier)
   - Format: Base58 string (~40-50 characters)

2. created_at
   - Token creation timestamp (ISO 8601 format)
   - Format: YYYY-MM-DDTHH:MM:SSZ

3. creator_address
   - Wallet address that created the token
   - Identified from earliest transaction or Metaplex metadata
   - Format: Base58 string (~40-50 characters)

4. price_highest
   - Highest price reached by this token (in SOL)
   - Format: Scientific notation (e.g., 1.2345e-08)
   - Empty if price never tracked

5. market_cap_highest
   - Highest market cap reached (in SOL)
   - Format: Fixed decimal (e.g., 1234.56)
   - Empty if market cap never tracked

6. rug_probability
   - Probability (0.0000-1.0000) that token is a rug pull
   - Calculated from on-chain analysis
   - Empty if analysis not yet complete

7. risk_level
   - Overall risk assessment: LOW, MEDIUM, HIGH, or CRITICAL
   - Based on multiple factors: rug indicators, creator history, funding sources
   - Empty if analysis pending

8. rug_indicator
   - Specific rug pattern detected, if any
   - Examples: "quick_peak_low_mc", "mint_concentration", etc.
   - Empty if no specific pattern detected

9. super_cluster_id
   - ID of the super cluster this creator belongs to
   - Format: "net_XXXXX" or "NONE" if not in any cluster
   - Super clusters represent coordinated funding networks

10. cluster_network_count
    - Number of funding networks in this super cluster
    - 0 if creator not in a cluster

11. cluster_creator_count
    - Number of creators in this super cluster
    - 0 if creator not in a cluster

12. cluster_risk_level
    - Risk level of the super cluster
    - LOW, MEDIUM, HIGH, or CRITICAL
    - NONE if creator not in a cluster

===============================================================================
FILTERING & USAGE TIPS
===============================================================================

To find highly suspicious tokens:
  - Filter where risk_level = "CRITICAL"
  - Filter where super_cluster_id != "NONE"
  - Sort by cluster_creator_count DESC

To find legitimate tokens:
  - Filter where risk_level = "LOW"
  - Filter where super_cluster_id = "NONE"

To analyze coordinated networks:
  - Group by super_cluster_id
  - Count creators per cluster
  - Analyze creators within same cluster

To examine specific creators:
  - Search for creator_address in column C
  - See all tokens created by that person
  - Check their risk patterns
