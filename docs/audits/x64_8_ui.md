# X64.8 Discovery UI

The progressive investigation is now:

`Behaviour -> Creator Identity -> Topology -> Funding Origin -> Operation Attribution -> Launch Results`

Creator Identity cards reuse the existing cohort-card control and display only non-zero branches. Selecting one filters the Behaviour cohort before topology counts are calculated. Breadcrumbs, URL state, stale-selection sanitization and upstream reset behavior include `creator_identity`.

Launch rows surface the mutually exclusive identity label and Disposable Creator percentage. Repeat Creator no longer appears as an additive Behaviour card. Existing funding and attribution display logic is unchanged.
