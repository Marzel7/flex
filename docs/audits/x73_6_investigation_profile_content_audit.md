# X73.6 Investigation Profile Content Audit

## Before

The profile repeated disposition, reasoning, and promotion readiness in six visible structures: hero metadata, overview prose, a `Why?` disclosure, primary KPI cards, promotion workflow cards, and evidence reconciliation. The default view also exposed a large metrics grid, lifecycle explanation, evidence statements, and confirmation history. Empty launch, timeline, walkback, and cluster tables retained full table chrome.

## After

The default dossier has one hero conclusion and a short Summary containing only relationships, next evidence, and valid actions. Disposition, reason, and promotion state each render once. Evidence is grouped into Supporting, Contradictory, and Missing disclosures. Members owns participants and launches; Analysis owns topology, infrastructure, walkback, behaviour, clusters, and advanced metrics; History owns timelines, legacy context, audit history, and confirmation events.

Large empty tables were replaced with compact sentence-level states. The profile uses the Registry disposition palette: green confirmed, orange review, blue infrastructure, slate unresolved, with colour restricted to the left border, badge, active tab underline, and valid links.

## Content measurement

| Measure | Before | After |
| --- | ---: | ---: |
| Default-view status/readiness presentations | 6 | 1 |
| Default-view top-level content blocks | 7 | 3 |
| Large empty table variants | 3 | 0 |
| Tabs with overlapping responsibilities | 5 | 0 |
| Hero explanatory sentences | Up to 3 | 1 |

The Summary composition removes the former explanation paragraphs, `Why?` disclosure, three-card status grid, duplicated lifecycle context, and eight-card metrics grid, reducing its visible explanatory content by more than half while preserving the underlying APIs and deep-link aliases.
