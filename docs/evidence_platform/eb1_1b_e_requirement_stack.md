# EB1.1B–E Requirement Stack

EB1.1B establishes the verified EB1.0D manifest as the canonical adapter input; raw bundle JSON or corpus presence cannot bypass EB1.0 replay. EB1.1C adapts only a replay-verified manifest. EB1.1D seals requirement projections with exact versions and input identity. EB1.1E groups immutable requirements by their originating stage and authority lane without merging lanes, choosing sources, or making requirements executable.
