How It Works:

                
    
                    
  • Measures how many creators appear in multiple clusters
    • 
                    
  • Denominator: Total unique creators in THIS cluster
    • 
                    
  • Numerator: Creators that also appear in other clusters
    • 
                    
  • Ratio: numerator ÷ denominator = reuse intensity
    • 
                    
  • Uses minimum-support thresholds to avoid false positives
    •

Creator Pool Tag Definitions & Guide


            

                
What Are Creator Pools?

                

                    A creator pool is a set of wallet addresses that are reused across multiple funding networks and clusters.
                    Instead of using unique wallets for each token launch, coordinated operations systematically reuse the same creators,
                    creating linkages between supposedly independent clusters. These tags identify the strength of creator pool coordination.
                

                

                    

                        ⚠️ Important: Tags are based on wallet reuse patterns and structural signals.
                        They indicate coordination likelihood, not intent or ownership. Use as a risk indicator, not definitive proof.
                    

                

            


            
            

                

                    INDEPENDENT
                    (Green)
                

                

                    
No creators reused across clusters

                    This cluster's creators appear only in this cluster and nowhere else. Each creator wallet is independent and not shared with other coordinated operations.

                    
Key Indicators:

                    
    
                        
  • creators_in_multiple_clusters = 0
    • 
                        
  • All creators unique to this cluster
    • 
                        
  • No connection to other clusters via shared creators
    • 
                    

                    
🟢 Risk: Low - Isolated operation

                

            


            
            

                

                    CREATOR POOL - WEAK
                    (Yellow)
                

                

                    
Minimal creator reuse

                    Some creators appear in multiple clusters, but the coordination signal is weak. Either few creators are reused, or the reuse ratio is below our minimum-support threshold.

                    
Minimum Support Requirements:

                    
    
                        
  • creators_in_multiple_clusters ≥ 1
    • 
                        
  • Below thresholds for SHARED or STRONG
    • 
                        
  • Marginal coordination signal detected
    • 
                    

                    
🟡 Risk: Medium - Monitor for escalation

                

            


            
            

                

                    CREATOR POOL - SHARED
                    (Orange)
                

                

                    
Solid creator pool coordination

                    Multiple clusters share a pool of creators with consistent coordination. Clear pattern of reusing the same launcher wallets across different funding networks.

                    
Minimum Support Requirements:

                    
    
                        
  • ✓ Min 5+ unique creators in cluster
    • 
                        
  • ✓ Min 2+ creators reused in other clusters
    • 
                        
  • ✓ Min 30%+ reuse ratio (2 ÷ 5)
    • 
                    

                    
🟠 Risk: High - Clear coordinated operations

                

            


            
            

                

                    CREATOR POOL - STRONG
                    (Red)
                

                

                    
Highly coordinated creator ecosystem

                    Strong evidence of an organized operation reusing creators systematically. Industrial-scale creator pool management with high concentration of reuse.

                    
Minimum Support Requirements:

                    
    
                        
  • ✓ Min 10+ unique creators in cluster
    • 
                        
  • ✓ Min 5+ creators reused in other clusters
    • 
                        
  • ✓ Min 50%+ reuse ratio (5 ÷ 10)
    • 
                    

                    
🚨 Risk: CRITICAL - Industrialized operations

                

            


            
            

                
Key Metrics Explained

                

                    

                        
creators_unique

                        
The actual count of distinct creator wallets in THIS cluster (denominator for reuse ratio)

                    

                    

                        
creators_in_multiple_clusters

                        
How many of those creators also appear in OTHER clusters (numerator for reuse ratio)

                    

                    

                        
reuse_ratio

                        
creators_in_multiple_clusters ÷ creators_unique = coordination intensity

                    

                    

                        
max_clusters_per_creator

                        
The creator with highest reuse appears in this many clusters
