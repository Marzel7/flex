HOW IT WORKS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Webhook arrives with transfers
2. Addresses extracted and queued for analysis (no blocking)
3. Return 200 OK immediately
4. Worker processes 5 creators at a time in background
5. Analyzes using 7 database queries
6. Caches findings as JSON with risk score
7. Reschedules based on activity level (high: 1h, low: 24h)
8. Results visible on dashboard instantly

  creator_address (PRIMARY KEY)

Indexes:
  idx_creator_analysis_status
  idx_creator_analysis_priority
  idx_creator_analysis_next

TROUBLESHOOTING

Queue not processing?
  → Check: ps aux | grep webhook_worker
  → Logs: tail -f flask.log | grep CREATOR_ANALYSIS
  → Restart: python3 webhook_worker.py

Queue stuck on analyzing?
  → Reset: UPDATE creator_analysis_queue SET status='retry', locked_until=0
           WHERE status='analyzing';

Force reanalysis?
  → Update: UPDATE creator_analysis_queue SET status='retry', next_analysis_at=0
            WHERE creator_address='YOUR_ADDRESS';
