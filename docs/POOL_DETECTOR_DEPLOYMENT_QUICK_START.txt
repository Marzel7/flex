================================================================================
THREE-STAGE VALIDATION LOGIC
================================================================================

STAGE 1: Owner Filter
  if account.owner in AMMPrograms.ALL:
      continue to Stage 2
  else:
      skip this account

STAGE 2: Size Filter
  if data_len >= MIN_POOL_SIZE[owner]:
      candidate is valid
  else:
      reject (log if data_len < 32: "helper PDA")

STAGE 3: Parser Validation
  parser = PoolParserDispatcher.for_program(owner)
  if parser.try_parse(data) succeeds:
      RETURN pool address ✅
  else:
      try next candidate or fallback

FALLBACK: Vault Discovery + Parser Validation
  for vault in getTokenLargestAccounts():
      authority = parse_token_account(vault).authority
      if authority.owner in AMMPrograms.ALL:
          if parser.try_parse(authority.data):
              RETURN authority ✅

TROUBLESHOOTING
================================================================================

PROBLEM: "No module named pool_parser_dispatcher"
SOLUTION: Check syntax validation passed, restart listener

PROBLEM: No candidate summary in logs
SOLUTION: Wait for next token launch, or check transaction has accounts

PROBLEM: All candidates rejected
SOLUTION: May be expected if pool isn't in transaction, fallback will try

PROBLEM: Parser validation logs not appearing
SOLUTION: Parser should be called for all candidates >= min size. Check logs.

PROBLEM: Fallback vault discovery fails
SOLUTION: Normal if pool doesn't exist yet. No error, just "failed to resolve"
