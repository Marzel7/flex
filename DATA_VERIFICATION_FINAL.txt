CORRECT QUERY (use this):
────────────────────────
SELECT
  cluster_id,
  COUNT(*) AS funders,
  MAX(network_size) AS network_size,
  MAX(total_volume_sol) AS cluster_volume_sol
FROM funder_networks
WHERE cluster_id IS NOT NULL
GROUP BY cluster_id
ORDER BY funders DESC;

Result: 9 rows, total SOL = 18,014.32 ✅


INCORRECT QUERY (don't use):
─────────────────────────────
SELECT SUM(total_volume_sol) FROM funder_networks WHERE cluster_id IS NOT NULL;

Result: 1,628,741.94 ❌
Reason: Sums cluster volume once per funder row (95 rows × 17,087 = 1,623,265 just for FUNDERS_1)


TOTAL SOL QUERY (correct):
──────────────────────────
SELECT SUM(cluster_volume_sol) FROM (
  SELECT cluster_id, MAX(total_volume_sol) AS cluster_volume_sol
  FROM funder_networks
  WHERE cluster_id IS NOT NULL
  GROUP BY cluster_id
);
