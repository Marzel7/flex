================================================================================
DATABASE TABLES
================================================================================

sol_transfers:
  - Stores deduplicated SOL transfers from webhooks
  - PRIMARY KEY: signature (automatic deduplication)
  - Indexes: source, destination, block_time, received_at

address_activity:
  - Rolling statistics for each address
  - tx_5m, tx_1h, tx_24h (transaction counts)
  - sol_in/out for each time window
  - last_processed_at, last_rpc_fetch_at
  - Indexes: last_seen_at, updated_at

work_queue:
  - Priority queue for address processing
  - priority (computed score)
  - next_run_at (when eligible for processing)
  - locked_until (prevents concurrent processing)
  - attempts (processing counter)
  - Indexes: priority DESC, next_run_at ASC
