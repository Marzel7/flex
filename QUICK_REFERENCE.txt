                         KEY RELATIONSHIPS
================================================================================

SENDER
  ↓ (sends SOL)
FUNDER
  ↓ (funds creator)
CREATOR
  ↓ (sends SOL)
RECIPIENT

Coordinated Pattern: Creator A → Funder → Creator B
  = Creator A sends to a Funder who funds Creator B
  = Indicates coordination (same actors)
  = Confidence: 70-100

Self-Funding Pattern: Creator → Intermediary → Funder → Creator
  = Creator distributes to many intermediaries
  = All intermediaries only fund back to creator
  = Creator then launches multiple tokens
  = Example: 942 intermediaries, 23 tokens launched

                         COMMON QUERIES
================================================================================

1. Is a creator self-funded?
   SELECT is_self_funding FROM creator_self_funding 
   WHERE creator_address = '...'

2. Find all creators funded by a specific funder
   SELECT DISTINCT creator_address FROM creator_funders
   WHERE funder_address = '...' ORDER BY amount_sol DESC

3. Find coordinated creators
   SELECT creator_a, creator_b FROM coordinated_creator_edges
   WHERE confidence >= 80

4. Find funding chains
   SELECT * FROM funding_chains
   WHERE confidence >= 85 AND chain_type = 'CREATOR_TO_FUNDER_TO_CREATOR'

5. Analyze a network
   SELECT * FROM creator_networks
   WHERE network_name = '...'

6. Get super cluster info
   SELECT * FROM super_clusters
   WHERE super_cluster_id = '...'
