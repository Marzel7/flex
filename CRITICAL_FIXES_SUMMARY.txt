Impact: Queried wrong account's history, extracted creator from wrong data
Fix: Extract bonding curve from Pump.fun instruction accounts using heuristics
Result: ✅ Now gets actual bonding curve account

─────────────────────────────────────────────────────
Problem: Both if/else branches returned True (no real validation)
Impact: Status="confirmed" meaningless, can't distinguish valid from invalid

Result: ✅ Status now meaningful (confirmed vs unproven)

HOW IT WORKS NOW (Simplified)
================================================================================

STEP 1: Get True Earliest Signature
  FOR each page of signatures:
    IF empty page THEN mark proven and return
    ELSE continue to next page
  Result: Proven earliest_sig or None

STEP 2: Fetch Creation Transaction
  GET transaction for earliest_sig
  Result: Transaction object or None

STEP 3: Find Pump.fun Instruction
  FOR each instruction in transaction:
    IF instruction.programId in PUMPFUN_PROGRAM_IDS THEN
      FOR each account in instruction:
        IF writable AND not signer AND not system program:
          RETURN account as bonding_curve
  Result: Bonding curve PDA or None

STEP 4: Validate Transaction
  IF mint in transaction accounts AND Pump.fun program found:
    status = "confirmed"
  ELSE:
    status = "unproven"
  Result: Meaningful status classification
